# Maicon Joder | Psicologia

Site institucional desenvolvido para apresentar o trabalho do psicólogo **Maicon Joder Pereira da Silveira**, seus serviços e canais de contato profissional.

O projeto tem como proposta transmitir acolhimento, tranquilidade e profissionalismo por meio de um design minimalista, responsivo e de uma identidade visual inspirada em tons de verde.

## 🌐 Acesse o projeto

- **Site publicado:** [maiconjoder.vercel.app](https://maiconjoder.vercel.app/)
- **Repositório GitHub:** [github.com/SimonePenido/maicon_joder](https://github.com/SimonePenido/maicon_joder)

## 🎯 Sobre o projeto

O site foi desenvolvido para funcionar como uma apresentação profissional, facilitando o acesso às informações sobre o psicólogo, modalidades de atendimento e formas de contato.

A interface foi planejada para proporcionar uma navegação simples e intuitiva, priorizando a legibilidade, a organização das informações e a experiência do usuário em diferentes dispositivos.

## ✨ Funcionalidades

- Layout responsivo para computadores, tablets e smartphones.
- Navegação entre as seções da página.
- Menu adaptado para dispositivos móveis.
- Seção de apresentação profissional.
- Apresentação dos serviços psicológicos oferecidos.
- Cards com modalidades de atendimento.
- Botões de contato integrados ao WhatsApp.
- Links para redes sociais e e-mail.
- Animações suaves de entrada durante a rolagem.
- Efeitos de interação em botões e cards.
- Atualização automática do ano no rodapé.
- Página de Política de Privacidade.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação semântica e organização do conteúdo.
- **CSS3:** estilização, identidade visual, animações e responsividade.
- **JavaScript:** interatividade, menu mobile e efeitos de rolagem.
- **Git e GitHub:** versionamento e hospedagem do código-fonte.
- **Vercel:** publicação e hospedagem do site.

## 🎨 Identidade visual

A identidade visual utiliza uma paleta de cores baseada em tons de verde, transmitindo equilíbrio, serenidade e acolhimento.

| Cor | Código | Aplicação |
|---|---|---|
| Preto esverdeado profundo | `#101816` | Contraste e profundidade |
| Verde profundo | `#202D28` | Fundos e seções |
| Verde-musgo escuro | `#35473D` | Elementos de destaque |
| Verde médio | `#52675A` | Elementos complementares |
| Verde-sálvia | `#829486` | Detalhes e destaques |
| Cinza esverdeado claro | `#C1C9BD` | Textos e elementos claros |

## 💻 Como executar localmente

1. Clone o repositório:

```bash
git clone https://github.com/SimonePenido/maicon_joder.git
```

2. Acesse a pasta do projeto:

```bash
cd maicon_joder
```

3. Abra o arquivo `index.html` no navegador ou utilize a extensão **Live Server** no Visual Studio Code para executar o projeto em um servidor local.

Não é necessário instalar dependências ou executar comandos de build.
